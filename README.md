# 小说合集库

`slow-world-novel` 是个人长篇小说创作合集仓库。

它不是单一本小说，而是所有小说项目的统一内容库，由 NarrativeOS 负责生产、管理和迭代。

## Repository Role

- 保存所有小说作品
- 管理世界观、人物、时间线
- 保存章节版本和 AI 审核记录
- 沉淀创作经验

## Structure

```text
novels/
 ├── slow-world/
 │   ├── bible/
 │   ├── characters/
 │   ├── outline/
 │   ├── chapters/
 │   ├── reviews/
 │   └── versions/
 │
 └── future-project/

shared/
 ├── writing-style/
 ├── world-rules/
 └── themes/

universe/
└── timeline/
```
