# 慢速世界

AI-assisted long-form novel project created with NarrativeOS.

## Genre

Post-apocalypse / Transmigration / Ability / Dungeon exploration

## Project Structure

- bible: world settings
- characters: character profiles
- outline: story planning
- chapters: novel chapters
- reviews: AI review records
- versions: revision history

## Workflow

Writer Agent → Review Team → Revision → Final Chapter
