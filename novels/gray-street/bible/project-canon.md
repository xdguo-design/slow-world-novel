# 《灰街》项目 Canon

## 已锁定事实

- 主角始终是埃文·格雷。
- 雷蒙德·克莱是已死亡的遗物原主人和 SV-7 事件链关键人物。
- 第一幕的调查起点是克莱遗产中的异常怀表。
- 怀表可出现只有埃文能看到的文字；哈里看不到“四日”。
- 怀表曾显示“四日”“归还第一笔”“不是这里”“归还”与 SV-7。
- SV-7 与已撤销的第七码头资产处有关。
- 米拉·阿尔瓦曾与克莱同在第七码头资产处合影中。
- 十三号仓保存过银质身份牌与封存钥匙。
- 银牌刻有 `SV-7 / 05` 与 `MIRA ALVA`。
- 红发女人在克莱死亡前九天取走钥匙；她戴手套。
- 第一笔归还在银牌交给米拉后完成，怀表文字清空。
- 第五节结尾 SV-7 再次极淡浮现，为后续七号箱线索。
- 神秘机制原因允许未知，但已展示的可观测现象必须一致。
- 现实程序不能因超自然目标消失：遗产清算、寄存、核验、授权、所有权和账目后果必须连续。

## 当前 Skill Evolution 必须修正的硬问题

1. 钥匙保管链：六年前只能是仓内转柜/单独封存，不能写成已经离库；九天前才是唯一一次真正领取离库。
2. 倒计时样本：克莱与埃文看到的可观测过程要兼容，不提前解释机制原因。
3. 第一节停表时间若用于死亡窗口证据，要表达成唯一可读的约 1:55:32。
4. 费恩让埃文带走银牌必须区分“实物核验”与“所有权转移”，并保留事务所账目后果。
5. 米拉的撒谎观察只能基于当场可观察行为，不可凭一次见面概括成长期习惯。
6. 文书字段差异可以来自记录范围不同，但正文要给最小范围锚点。
7. 不把“怀表表链断裂”误判成“机芯不应走”的物理矛盾。

## 文风

- 完整段落、自然长短句搭配、连续叙事。
- 避免大量短句连续断行和台词墙。
- 对话与动作、视线、环境和任务自然结合。
- 减少解释性废话和“作者替读者总结”。
- 悬疑通过事实与行为推进，不写成规则说明书。
