# 慢速世界

《慢速世界》是小说合集中的第一个长篇项目。

## Type

末世 / 穿越 / 异能 / 副本探索

## Structure

- bible: 世界观
- characters: 人物 DNA 与角色记忆
- outline: 长线规划
- chapters: 正文
- reviews: AI 审核记录
- versions: 章节版本


## NarrativeOS Contract

NarrativeOS 以本目录作为《慢速世界》的作品根目录。

- `bible/`：作品级世界观；当前历史资料 `/bible/world.md` 仍被兼容读取。
- `characters/`：人物 DNA、长期角色记忆。
- `outline/`：卷纲、章纲和未完成情节线。
- `chapters/`：人工确认后的正式章节。
- `reviews/`：对应创作任务的 Reviewer 审核记录。
- `versions/`：人工确认时的版本归档。

`/shared/writing-style/` 作为跨作品共享写作规范，可由 NarrativeOS 导入 Skill Engine。

目前仓库还没有正式章节正文。不会为了通过平台验收而提交测试章节；第一章正式内容进入后，再执行完整 Writer → Reviewer → Revision → 人工确认 → 归档与恢复演练。
