# 《零点站台》

一部都市悬疑 / 轻科幻短篇小说。

## 一句话简介

每天 00:07，已经停运七年的地铁站会出现一班不存在的列车。

林桥在车里看见了失踪七年的妹妹。

而妹妹所在的世界里，死去的人是他。

## 核心命题

如果另一条人生里，你失去的人还活着，你有没有权利把他带回来？

## 结构

第一卷《回程》，共 8 章：

1. 七年前停运的站
2. 四十七秒
3. 没有停运的青屿站
4. 少掉的座位
5. 一八点二千瓦
6. 两个世界同时进站
7. 回程
8. 零点零八分

## 项目用途

这是 NarrativeOS 的第一部完整验收小说，同时也是独立可阅读作品。

平台测试可以使用本项目的：

- `bible/`：世界观规则
- `characters/`：人物资料
- `outline/`：卷纲
- `chapters/`：正式章节正文
- `reviews/`：评审归档
- `versions/`：版本归档
