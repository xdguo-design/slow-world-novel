# 《零点站台》

NarrativeOS 全链路生产验收小说。

## 类型

都市悬疑 / 轻科幻 / 时间异常

## 核心设定

每天 00:07，已经停运七年的临江地铁四号线会在旧终点站出现一班没有运营编号的列车。

它只停 47 秒。

上车的人会看见自己人生里“没有发生的那条路”。

## 用途

本作品专门用于 NarrativeOS 生产闭环验收，和《慢速世界》正式内容完全隔离。

验收范围：

- 内容库预检与资料导入
- Writer
- Continuity Reviewer
- Plot Reviewer
- Style Reviewer
- Revision
- 人工确认
- chapters / reviews / versions 归档
- 版本恢复
- content-sync 重试
- 重启后状态恢复
